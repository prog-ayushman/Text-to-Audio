# Text-to-Music Assistant

A local text-to-music application that turns a written description (for example
"calm piano melody") into a short WAV audio clip, using the pretrained
`facebook/musicgen-small` model. It also records measurements for each clip and
includes a small evaluation of eight fixed prompts.

- Model: `facebook/musicgen-small`
- Revision: `4c8334b02c6ec4e8664a91979669a501ec497792`
- Output: mono, 32 kHz, 16-bit WAV
- No training or fine-tuning is done here; the project only runs inference.
- Check the license terms on the model card before using the output beyond coursework:
  https://huggingface.co/facebook/musicgen-small

## Setup (Windows, CPU only)

```
python -m venv .venv
.venv\Scripts\activate
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install transformers scipy numpy streamlit pytest
```

Versions used for the recorded results: Python 3.11.9, transformers 5.22.2,
torch 2.15.0 (CPU), scipy 1.17.1, numpy 2.4.6, streamlit 1.67.0, pytest 9.2.0.

The first run downloads about 2.36 GB of model files from Hugging Face and needs
internet access. If the download fails with a connection error, run this in the
same terminal and try again:

```
$env:HF_HUB_DISABLE_XET = "1"
```

The laptop used for testing had 8 GB of RAM. Close heavy programs before generating.

## Usage

Web interface:

```
streamlit run app.py
```

Command line:

```
python cli.py "calm piano melody" --seconds 5 --seed 0 --output outputs\clip.wav
```

Run the evaluation (generates 8 clips, takes roughly 10 to 15 minutes on a CPU):

```
python evaluate.py
python evaluate.py --ratings-only
```

Run the tests (they do not load the model):

```
pytest
```

## Input rules

- Prompt: non-empty text, up to 300 characters
- Duration: 1 to 10 seconds
- Seed: a whole number (the same prompt and seed give the same clip on the same setup)

## Files

| File | Purpose |
|---|---|
| predictor.py | Validation, model loading, generation, WAV writing and measurements |
| app.py | Browser interface with audio player and download button |
| cli.py | Terminal tool with JSON output |
| evaluate.py | Generates the eight fixed prompts and saves the summary |
| examples/audio/ | Clips generated by the evaluation |
| examples/sample_results.json | Per-clip measurements, ratings and summary |
| examples/ratings.json | Listening ratings (1 to 5) given by the author |
| tests/ | Sixteen tests using no model |
| pytest.ini | Test configuration |

## Measurements recorded for each clip

Measured duration, generation time, real-time factor (generation time divided by
clip length), peak level, RMS level, silence fraction (share of 20 ms frames with
RMS below 0.01) and a check that all samples are valid numbers.

## Evaluation note

The evaluation uses eight prompts written before generation, each generated once
with seed 0 and a requested length of 5 seconds. On the test laptop, the mean
generation time was about 75 seconds per clip. The ratings come from one listener
(the author) and the mean was 3.875 out of 5. The flute prompt produced piano and
the rain-and-thunder prompt produced noise. This is a small demonstration, not a
general measure of audio quality.

## Limitations

- Short clips only (up to 10 seconds here)
- English prompts; other languages were not tested
- Designed for music; sound effects are outside the purpose of the model
- Instrument requests are not always followed
- Slow on a CPU (about 15 times slower than real time in these tests)
